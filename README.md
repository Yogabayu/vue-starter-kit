# Laravel + Vue (Inertia) Starter Kit

A modern Laravel 12 + Vue 3 starter using Inertia, Vite, Tailwind CSS v4, TypeScript, shadcn-vue, Fortify auth, Ziggy, and Wayfinder route helpers. Includes SSR support with Inertia 2 and a clean DX with eslint/prettier.

## Stack

- Backend: Laravel 12, Fortify (auth), Jobs/Queue (database), Cache (database)
- Frontend: Vue 3 (TS, Composition API), Inertia 2, Vite 7, Tailwind CSS v4, shadcn-vue, vue-sonner
- DX: TypeScript, ESLint 9, Prettier 3, Wayfinder (typed route helpers), Ziggy (JS route access)
- SSR: Inertia SSR via `php artisan inertia:start-ssr`

## Prerequisites

- PHP 8.2+
- Composer 2.6+
- Node.js 18.18+ and npm 9+ (for Vite 7 and Tailwind v4)
- MySQL 8+ (or compatible) for `DB_CONNECTION=mysql`
- Optional: Redis if you switch cache/queue drivers

## Quick Start

```bash
git clone <repo-url>
cd vue-starter-kit

# Install PHP deps and app key
composer install
cp .env.example .env
php artisan key:generate

# Create database and configure .env (DB_* vars)
php artisan migrate --force

# Install frontend deps
npm install

# Start dev servers (PHP, queue, Vite) in one go
composer dev
```

Now visit `http://127.0.0.1:8000`.

## Environment & Configuration

Copy `.env.example` to `.env` and update at least:

- `APP_NAME`, `APP_URL`
- `DB_CONNECTION`, `DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`
- `SESSION_DRIVER=database`, `QUEUE_CONNECTION=database` (as configured)
- `MAIL_*` if you want real emails; otherwise defaults to `log`
- `VITE_APP_NAME` (used in browser title)

Run initial setup at any time using the provided Composer script:

```bash
# Installs deps, generates key, runs migrations, installs npm, and builds assets
composer run setup
```

## Development

Available scripts and what they do:

- PHP + Queue + Vite together
  - `composer run dev`

- Enable SSR (optional)
  - Build: `npm run build:ssr`
  - Run: `composer dev:ssr`

- Frontend only
  - `npm run dev` — Vite dev server
  - `npm run build` — Production asset build

- Code quality
  - `npm run lint` — ESLint (fix)
  - `npm run format` — Prettier write
  - `npm run format:check` — Prettier check

### Useful artisan commands

- `php artisan migrate` — Run DB migrations
- `php artisan queue:listen --tries=1` — Dev queue worker (already started by `composer dev`)
- `php artisan storage:link` — Public storage symlink
- `php artisan optimize` — Cache config/routes/views/events

## Frontend Notes

- Entry points: `resources/js/app.ts` (SPA), `resources/js/ssr.ts` (SSR)
- Pages: `resources/js/pages/**` via Inertia resolver
- Route helpers: `resources/js/routes/**` generated by Wayfinder
- Tailwind: Tailwind v4 + `@tailwindcss/vite`
- Components: shadcn-vue primitives in `resources/js/components/ui`

## Testing

- PHP tests: `composer test`

Add Pest/PhpUnit tests under `tests/` as usual.

## Deployment

General steps for typical Nginx + PHP-FPM hosting:

1) Server packages
- PHP 8.2+ with required extensions (bcmath, ctype, fileinfo, json, mbstring, openssl, pdo, tokenizer, xml, curl)
- Composer 2.6+
- Node 18.18+ (build server or CI only)

2) Clone and install
```bash
composer install --no-dev --prefer-dist --optimize-autoloader
cp .env.example .env
php artisan key:generate --force
```

3) Configure environment
- Update `.env` values for `APP_ENV=production`, `APP_DEBUG=false`, `APP_URL`, DB and MAIL

4) Build assets (in CI or on server)
```bash
npm ci
npm run build
```

5) Database and storage
```bash
php artisan migrate --force
php artisan storage:link
```

6) Optimize application caches
```bash
php artisan optimize
```

7) Permissions
- `storage` and `bootstrap/cache` writable by the web user (e.g., `www-data`)

8) Queue worker (Supervisor)
- Example program config:
```
[program:laravel-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/html/artisan queue:work --sleep=3 --tries=3 --max-time=3600
autostart=true
autorestart=true
numprocs=1
redirect_stderr=true
stdout_logfile=/var/log/supervisor/laravel-worker.log
```

9) Scheduler (cron)
```
* * * * * php /var/www/html/artisan schedule:run >> /dev/null 2>&1
```

10) Nginx (example)
```
server {
    server_name example.com;
    root /var/www/html/public;

    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/run/php/php8.2-fpm.sock;
    }

    location ~* \.(js|css|png|jpg|jpeg|gif|svg|ico|woff2?)$ {
        try_files $uri =404;
        expires 7d;
        access_log off;
    }
}
```

### SSR in production (optional)

If you deploy with SSR:

- Build SSR bundle: `npm run build:ssr`s
- Run SSR server: `php artisan inertia:start-ssr` (daemonize with Supervisor/PM2)

## Troubleshooting

- Port in use: Change dev server port or stop conflicting services.
- Vite build errors: Ensure Node 18.18+ and a clean `node_modules` (`rm -rf node_modules && npm ci`).
- 500 after deploy: Run `php artisan config:clear route:clear view:clear` then `php artisan optimize`.
- Missing storage files: `php artisan storage:link`.
